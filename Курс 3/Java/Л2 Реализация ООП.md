- `public` - доступ без ограничений
- `private` - доступ только из данного класса
- `protected` - доступ из данного класса, из всех классов потомков пакета
- без описателя - доступ из всех классов пакета

Некоторые важные пакеты Java:

- `java.io` - пакет поддержки ввода-вывода

 Все классы в Java являются наследниками одного общего класса `Object`. А значит у всех классов имеется ряд методов унаследованных от `Object`:
 - `Object.hashCode()` - для каждого объекта вычисляется хеш-код (объекты сравниваются по хешам). Учитываются не только значения полей, но и адрес расположения в памяти.
 - `Object.equals()` - функция сравнения объектов. При использовании метода из класса `Object` используется сравнение места в памяти.
 - `Object.toString()` - строковое представление объекта.
 - `Object.finalize()` - объект из динамической памяти удаляется из памяти garbage collector-ом (переопределять не надо).
 - `Object.getClass()` - получение класса объекта.

#### Наследование классов

``` java
class A { // super-класс
    // тело класса A
}

class B extends A {
    // тело класса B
}
```

Множественное наследование **запрещено**.

Если есть конструктор с параметром, то и у наследников тоже должен быть конструктор с параметром, который будет вызывать конструктор базового. Конструктор вызывается как `super()`. 

Условия преобразования понижения (базовый -> производный):
- Явное преобразование
- Объект принадлежит целевому классу

Перед понижением необходимо проверить является ли объект экземпляром класса при помощи `instanceof`.
#### Полиморфизм

**overloading** - совместное использование

Пример 1:
``` java
class X {
	int f() { ... }
	void f(int k) { ... }
}
```

Пример 2:
``` java
class Base {
	void f(int k) { ... }
}

class Derived extends Base {
	int f(String s, int k) { ... }
}
```

**overriding** - переопределение

``` java
class Base {
	int f(int k) { ... }
}

class Derived extends Base {
	@Override // необяязательно, но желательно
	int f(int k) { ... }
}
```

Спецификатор `final` - в отношении переменных и полей означает констант, которую нельзя изменять и нужно проинициализировать при описании. В отношении параметров означает что такие параметры нельзя изменять.

`final` в сочетании со `static` даёт глобальную константу, существующую в единственном экземпляре.

`final` по отношению к методам означает что метод в порождённых классах нельзя переопределить.

`final` в отношении классов запрещает его наследование.

#### Интерфейсы

**`interface`** - это полностью абстрактный класс, не содержащий никаких полей, кроме статических констант и никаких методов кроме абстрактных. Сделано это для того чтобы производить множественное наследование от интерфейса. Говорят что один класс наследует другой (`extends`), но реализует интерфейс (`implements`).

``` java
public interface XXX {
	...
	int f(String s);
	...
}

public interface YYY {
	...
	int g(String s);
	...
}

public class R implements XXX,YYY {
	...
	public int f(String s) { ... };
	public int g(String s) { ... };
	...
}
```

В интерфейсах можно определять `default` методы, которые будут одинаковы во всех производных классах.

#### Дженерики

Дженерики (обобщения) - особые средства языка для реализации обобщённого программирования: особого подхода к описанию данных и алгоритмов, позволяющего работать с различными типами данных без изменения их описания.

> "Плюс минус" - Пышницкий К.М.

Появились в Java 5.0.

``` java
public static void main(String[] args) {
	List<String> list = new ArrayList();
	list.add("27");
	String data = list.get(0);
	System.out.println(data);
}
```

Без указания типа данных коллекция будет хранить объекты типа `Object`.

С Java 7 появилось указание типа для создания объектов справа:

``` java 

public static void main((String[] args) {
	List<Integer> list = new ArrayList<>();
	list.add(27);
	list.add(28);
	List<Integer> list1 = new ArrayList<>(list);
	Integer data = list1.get(0);
	System.out.println(data);
}
```

Дженерики можно применять и к функциям:

``` java
static class Util {
	public static <T> T getValue(Object obj) {
		return (T) obj;
	}
}

public static void main((String[] args) {
	List list = Arrays.asList("Sasha", "Kaznin");
	for (Object obj : list) {
		String test = Util.<String>getValue(obj);
		System.out.println(test);
	}
	
	list = Arrays.asList(67, 69);
	for (Object obj : list) {
		Integer test = Util.<Integer>getValue(obj);
		System.out.println(test);
	}
}
```

Дженерик можно сделать классом:

``` java

class Class<T> {
	...
}
...
Class<Integer> = new Class<>();
```
