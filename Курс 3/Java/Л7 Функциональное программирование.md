#### Функциональный интерфейс
- Интерфейс содержащий единственный абстрактный метод
- Может быть аннотирован как `@FunctionalInterface`

Пример функционального интерфейса:
``
``` java
@FunctionalInterface
public interface MyInterface {
	public double f();
}

MyInterface myInt = new MyInterface() {
	@Override
	public double f() {
		return 3.1415926;
	}
}
System.out.println(myInt.f);
```

Лямбда-выражения

```
([parameter]) -> lambda body
```

Однострочные: () -> System.out.println()

Блочные:
```
() -> {
	double pi = 3.1415;
	return pi;
}
```

Лямбда-выражения фактически являются безымянной функцией, где в скобках указываются параметры, а после стрелки тело функции.

Интерфейс можно описать следующим образом:
``` java
@FunctionalInterface
public interface MyInterface {
	public double f();
}

MyInterface myInt = (x) -> {return x};
System.out.println(myInt.f(3.1415));
```

Стандартные интерфейсы:
- `Runnable` - метод `run()` (для потоков)
- `Comparator` - метод `compare()`

Параметризованный функциональны интерфейс:

``` java
@FunctionalInterface
public interface MyInterface<T> {
	public T f(T t);
}
```

Стандартный интерфейс: `Predicate<T>`
#### Ссылки на методы

Ссылки на методы - команктные лямба выражения для методов у которых уже есть имя.
`object::InstanceMethod` - ссылается на объектный метод предложенного объекта

Пример:
`Math::max = (x,y)` равносильно `Math.max(x,y)`
#### StreamAPI

Стримы предназначены для реализация последовательных агрегаций, выполняемых через цепочку методов.

- Поток однотипных данных для однотипной обработки
- Промежуточные операции описывают рецепт обработки, но ничего не делают
- Вся работа производится при вызове терминальной операции

> "... терминальной операции. Например расстрелять." - Пышницкий К.М.

Три реализации:
- `IntStream`
- `DoubleStream`
- 

Примеры создания стримов:

Stream из List:
``` java
List<String> list new ArrayList<>();
list.stream();
```

Stream из Map:
``` java
Map<String, String> map new HashMap<>();
map.entrySet.stream();
map.values.stream();
```

Промежуточные операции:
- Провести операцию над каждым элементом - `peek()`
- Преобразовать данные к типу - `map()`
- Отфильтроватвь - `filter()`
- Удалить дубликаты
- ...

Терминальные операции:
- Собрать элементы и преобразовать к нужному типу - `collect()`
	- `Collectors.toList()`
	- ...
- Итерация по каждому - `forEach()`
- Узнать количество элементов - `count()`
- Найти минимум и максимум - `min()`, `max()`
- Найти первый подходящий - `findFirst()`
- Найти любой подходящий - `findAny()`
- Все ли соответствуют - `allMatch()`
- Вне не соответствуют - `noneMatch()`
- Один соответствуют - `anyMatch()`
- Сумма - `sum()`
- Сведение к одному результату - `reduce()`

Пример:
``` java
IntStream.of(120, 410, 85, 32, 314, 12)
	.filter(x -> x < 300)
	.map(x -> x + 11)
	.limit(3)
	.forEach(System.out::println);
```
