Классы-списки:
- `ArrayList`:
	- `ArrayList()`
	- `ArrayList(Collection coll)`
	- `ArrayList(int initCapacity)`
	При добавлении нового элемента, для которого нет места размер ArrayList увеличивается на 50%. При этом если что-то удалить, то размер остаётся тот же.
- `LinkedList`:
	- `LinkedList()`
	- `LinkedList(Collection coll)`
	Работает как динамический список. На конце находится null
- `ArrayDeque<E>` - обобщённая двунаправленная очередь, наследуя функционал от класса `AbstractCollection`, применяя интерфейс `Deque`.
- `PriorityQueue<E>` - приоритетная очередь

Считается что операция взятия по индексу работает быстрее в ArrayList потому что можно математически вычислить местонахождение элемента. Однако удаление и добавление элемента в середину происходит быстрее в LinkedList из-за того что для ArrayList требуются перестановки. Перебор обоих занимает одинаковое время.

> "Does anyone actually use LinkedList. I wrote it, and newer use it." - создатель ArrayList и LinkedList

Классы-множества:
- `HashSet`:
	- `HashSet()`
	- `HashSet(int capacity)`
	- `HashSet(int capacity, float loadFactor)`
	- `HashSet(Collection coll)`
	Неупорядоченное - работает как хеш таблица для объектов (для которых всегда есть хеш). Как только цепочка коллизий в хеш таблице станет длинной, в тот момент эта цепочка преобразуется в красно-чёрное дерево.
- `TreeSet`:
	- `TreeSet()`
	- `TreeSet(Comparator c)`
	- `TreeSet(Collection coll)`
	- `TreeSet(SortedMap sm)`
	Упорядоченное, требует компаратора (для пользовательских типов) - работает как дерево поиска, задействующее симметричный обход.

#### Пример создания коллекции

``` java
// range как в питоне
static List<Integer> rangeList(int fromInclusive, int toExclusive) {
	return new AbstractList<Integer>() {
		public Integer get(int index) {
			if (index < 0 || index >= size())
				throw new IndexOutOfBoundsException();
			return fromInclusive+index;
		}
		public int size() { return toExclusive - fromInclusive; }
	};
}

public static void main(String[] args) {
	List<Integer> rl = rangeList(0,10);
	System.out.println(rl);
}
```
