Фрейворк, позволяющий легко создавать web-страницы средствами языка Java.

Код разрешается брать с [vaadin.com](https://vaadin.com/docs/latest/).

Преимущества:
- Интерфейс пользователя
- Готовые темы
- Источники данных

Для создания Vaadin приложения есть два способа:
- "закат солнца вручную" - создать Java приложение и добавить множество фалов вручную
- Воспользоваться сборщиком приложений в Intellij - Maven или Gradle.

**Apache Maven**
- Упрощение процесса сборки
- Обеспечение единой системы сборки
- Предоставление качественной информации о проекте
- Поощрение лучших практик разработки

При создании проекта в Intellij используем Maven Archetype:
- Catalog: Maven Central (для дома) и `Default` (для лаб в чгу)
- Archetype: `com.vaadin: vaadin-architype-application`
