`try`
`catch`
`finally` - выполняется в любом случае
`throw`
`throws` - описывает какое исключение может выбросить метод

Классы исключений:
- `Object`
	- `Throwable`
		- `Error` (непроверяемые)
			- `ThreadDeath`
			- `StackOverflowError`
			- `OutOfMemoryError`
			- ...
		- `Exception`
			- `RuntimeException` (непроверяемые)
				- `IndexOutOfBoundsException`
				- `NullPointerException`
				- `ClassCastException`
				- `ArithmeticException`
				- ...
			- `ClassNotFoundException`
			- `IOException`
			- `FileNotFoundException`
			- `InstantiationException`
			- `NoSuchFieldException`
			- `NoSuchMethodException`
			- ...

Методы Exception:
- `toString()` - наименование класса + сообщение об ошибке
- `getMessage()` - сообщение об ошибке
- `getStackTrace()` - возвращает массив трассиворки стека
- `printStackTrace()` - отображает трассировку стека
