#### Проблемы разработки сложного ПО

%%Агетация срочной службы. Одна лекция лучше другой...%%
Чем сложнее задача, тем сложнее программное обеспечение.
Факторы увеличения сложности:
- Сложность формального определения требований - большое количество факторов, разработчики не являются специалистами в предметной области заказчика, требования могут быть размытыми.
  ![[Drawing 2026-02-17 14.11.18.excalidraw]]
- Отсутствие удовлетворительных средств описания поведения дискретных систем с большим числом состояний при недетерминированной последовательности входных изменений
- Коллективная разработка
- Необходимость увеличения степени повторяемости кода

#### Блочно-иерархический подход в создании сложных систем

Любую сложную систему можно представить в виде дерева, когда конечный объект делится на множество блоков, которые также делятся на блоки.

Также применяется локальная оптимизация - определяется на сколько блоков на уровне будет разбита программа.
#### Жизненный цикл и его модели

**Жизненный цикл информационных систем** - Это базовое понятие методологии проектирования информационных систем. 

**Жизненный цикл** - это непрерывный процесс, который начинается с момента принятия решения о необходимости создания программного обеспечения и заканчивается в момент полного изъятия из эксплуатации.
**Жизненный цикл** - интервал времени от идеи (требование заказчика) до прекращения сопровождения.

**Документ, регламентирующий жизненный цикл** - международный стандарт ISO/IEC 12207.

![[Drawing 2026-02-17 14.39.31.excalidraw]]

Структура жизненного цикла базируется на трёх группах процессов:
- Основные процессы
	- Приобретение
	- Поставка
	- Разработка
	- Эксплуатация
	- Сопровождение
- Вспомогательные процессы
	- Документирование 
	- Управление конфигурацией
	- Опеспечение качества
		- Верификация
		- Аттестация
		- Совместная оценка
		- Аудит
	- Разрешение проблем
- Организационные процессы
	- Управление
	- Усовершенствование
	- Создание инфраструктуры
	- Обучение

В разработку входят (ГОСТ 19.102-77 "Стадии разработки"):
- Постановка задачи
- Формирование спецификаций
- Детальное проектирование
- Кодирование
- Итеграция в существующие системы
- Тестирование
- Установка на оборудование заказчика
- Приёмка

#### Модели жизненного цикла

###### Каскадная модель

![[Drawing 2026-02-17 15.49.56.excalidraw]]

Пока не реализован один этап, не должен будет начат другой.
Не подходит для учебных проектов. Нет возможности пересмотра решений и возврата назад.
###### Модель с промежуточным контролем

Модификация каскадной схемы, где из каждого этапа можно вернуться в любой предыдущий. Но при этом имеет место ситуация, когда проект можно никогда не завершить.

#### Система автоматизированного проектирования (CASE)

Первый уровень:
- Основные усилия на анализ и проектирование
- Быстрое итерационное прототипирование
Второй уровень:
- Автоматическая генерация кодов
- Автоматическая генерация документации
- Автоматический контроль проекта
- Сопровождение спецификаций проектирования

Примеры:
- BPWin - CASE система первого уровня
- ERWin - CASE система второго уровня
- Rational Rose - CASE система второго уровня
