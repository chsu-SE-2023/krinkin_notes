#### Определение требований к ПО
##### Этап постановки задачи
Один из наиболее ответственных этапов создания программного продукта. На этом этапе формулируются основные требования к разрабатываемому ПО. Дальнейшая разработка полносттью зависит от результатов этапа.

Основные требования:
- правильность - соответствие тз
- универсальность - работа при любых допустимых данных, защита от неправильных данных
- надёжность - полная повторяемость результатов
- проверяемость - возможность проверки получаемых результатов
- точность результатов - погрешность не выше заданной
- защищённость - конфиденциальность данных
- программная совместимость
- аппаратная совместимость
- эффективность
- адаптируемость - возможность быстрой модификации
- повторная входимость - возможность повторного выполнения без перезагрузки с диска
- реентерабельность - позможность "параллельного" использования несколькими процессами

Перед проектированием производится **предпроектные исследования** - анализируются методы решения сформулированной задачи, анализируется структура автоматизированной системы.

Основные факторы определяющие характеристики разрабатываемого ПО:
- исходные данные, которые определяют функции программы
- среда функционирования
- возможное взаимодействие с другим ПО или техническими средствами

Порядок разработки ТЗ:
- Устанавливается набор выполняемых фнкций
- Определяется перечень результатов
- Уточняют среду функционирования ПО
- Регламентируют действия программы в случае сбоев оборудования

Принципиальные решения начальных этапов проектирования:
- Выбор архитектуры ПО
- Определение типа пользовательского интерфейса и технологии работы с документами
- Выбор подхода к разработке
- Определение языка и среды программирования

Основные типы архитектур ПО:
- Однопользовательская архитектура
	- Программа
	- Пакет программ
	- Программный комплекс
	- Программная система
- Многопользовательская архитектура

Типы пользовательских интерфейсов:
- Примитивный интерфейс
- Интерфейс меню
- Интерфейс со свободной навигацией
- Интерфейс прямого манипулирования

Выход: техническое задание
###### Разработка спецификации

- Спецификации ПО при структурном подходе
- Диаграммы переходов состояний STD)
- Функциональные диаграммы SADT (IDEF0)
- Диаграммы потоков данных SSADM (DFD)
- Структуры данных и диаграммы отношений (ERD)
- Математические модели задач

**Функциональные спецификации** - описывают функции разрабатываемого ПО
**Эксплуатационные спецификации** - определяют требования к техническим средствам, надёжности и информационной безопасности.

Требования к спецификации:
- Полнота (вся существенная информация)
- Точность (однозначное понимание)
