Единая система программной документации - ГОСТ 19.004-80

**Программное изделие** - программа на носителе являющаяся продуктом промышленного производства

ТЗ к производственной практике выполняется с учётом ГОСТ 19.201-78

ГОСТ 19.301 - порядок испытаний программного обеспечения

**Технологии программирования** - совокупность методов и средств, используемых в процессе разработки программного обеспечения

Технология определяет способ описания модели при проектировании программного обеспечения

#### Этапы развития программирования

- **Этап "стихийного" программирования (1960-е - 1980-е) - отсутствовали технологии, программирование было искусством.**
	- Программы записывались в кодах
	- Появление ассемблеров
	- Языки программирования высокого уровня - Fortran и Algol
	- Появление подпрограмм
	- Создание понятия локальных данных
	- Использование goto
- **Структурный подход (середина 1960-х - середина 1980-х)**
	- Процедурная декомпозиция - метод пошаговой детализации
	- Структурирование данных - возможность создания пользовательских типов данных
	- Модульное программирование
	(примерный объём - 100000 операторов)
- **Объектный подход (середина 1980-х - начало 2000)**
	- Объектная декомпозиция
	- Появление систем визуального программирования - Delphi, C++ Builder
- **Компонентный подход и CASE-технологии (начало 2000 - настоящее время)**
	- Появляется возможность сборки программы в виде COM-объектов (разбиение на несколько приложений, общающихся между собой, внедрение библиотек). Приложения могут быть разработаны на разных языках
	- Появление возможности CASE-систем - средство автоматизации проектирования программного обеспечения
