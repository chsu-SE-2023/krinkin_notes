#### Диаграммы потоков данных (DFD)

Строим по нотации Гейна-Сарсона

Внешние сущности только на контекстной диаграмме

Пунктирные - управляющие потоки данных
T переключатель - переключатель потока данных в управляющий
А переключатель - переключатель потока данных в управляющий и наоборот
E/D переключатель - двухканальный A переключатель

При проектировании спецификаций описываются **абстрактные модели** данных - множество, кортеж, список, вектор, матрица, цепь, цикл, дерево и т.д.

При проектировании программного продукта используются **конкретные модели** данных - классы, структуры, перечисления.
##### Диаграммы Джексона

Структуру данных так же как и структуру программы можно строить с использованием трёх конструкций:
- последовательность
- выбор
- повторение
##### Диаграммы Орра (скобочные диаграммы)

Реализация диграммы Джексона при помощи фигурных скобок:
- последовательность - `A { B C D }`
- выбор - `S { P + Q }`
- повторение - `I { X n times }`
Первая буква - идентификатор, остальная часть - набор символов (букв и цифр)
