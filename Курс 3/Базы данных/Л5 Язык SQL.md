s**SQL (Structured Query Language)** - непроцедурный язык, состоящий из трёх групп операторов: _SQL = DDL (Data Definition Language) + DML (Data Manipulation Language) + DQL (Data Query Language) + ..._. Используется для управления базами данных.

![[Drawing 2025-10-29 10.43.35.excalidraw]]

SQL появился в середине 1970-х в рамках проекта первой экспериментальной реляционной СУБД System R (там он назывался SEQUEL (Structured English Query Language)). Уже тогда он был полным языком баз данных:
- средства определения и манипулирования схемой БД;
- манипулирование записями БД;
- операторы запросов;
- операторы определения ограничения целосности;
- операторы представлений;
- операторы триггеров;
- операторы определения структур физического уровня для эффективного выполнения запросов (индексные файлы);
- операторы авторизации доступа к отношениям и полям;
- операторы работы с точками сохранения транзакции и откатов;
- и т.д.

#### SQL в прикладном программировании

В SQL 1 уже были определены способы взаимодействия с базой данных из прикладной программы, написанной на языке высокого уровня. 

Ранее использовались:
- COBOL
- FORTRAN
- PL 1
- PASCAL
- C

Способы взаимодействия:
- модульный принцип - операторы SQL собраны в модуль. Прикладная программа вызывает процедуры модуля, передаёт её фактические параметры, получает ответные параметры. Модуль компилируется отдельно от прикладной программы, тем самым порождается набор хранимых процедур.
- встроенный SQL - непосредственно в программе на ЯВУ имеются sql операторы. Обмен данными происходит через переменные, SQL операторы компилируются каждый раз при их использовании.
#### Типы данных в SQL

| Тип данных                                    | Обозначение                            | Размер                                                     | Диапазон                                       |
| --------------------------------------------- | -------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------- |
| Целые числа                                   | `INT (INTEGER)`                        | 4 байта                                                    | `-2^31` : `+2^31`                              |
|                                               | `SMALL INT`                            | 2 байта                                                    | -32768 : +32767                                |
|                                               | `TINY INT`                             | 1 байт                                                     | 0 : 255                                        |
| C плавающей точкой<br>(приближённые числовые) | `FLOAT (FLOAT (N))`                    | 8 байт                                                     | 15 знаков (N = 8 : 15)                         |
|                                               | `REAL (FLOAT (N))`                     | 4 байта                                                    | 7 знаков (N = 1 : 7)                           |
| Денежные суммы                                | `MONEY`                                | 8 байт                                                     | -922трл. : +922трл.<br>4 знака после запятой   |
|                                               | `SMALL MONEY`                          | 4 байта                                                    | -214000 : +214000<br>4 знака после запятой<br> |
| Символьные (фикс. длины)                      | `CHAR [(N)] (CHARACTER [(N)])`         | N байт                                                     | N = 1 : 255<br>(Без указания N = 1)            |
| Символьные (перем. длинны)                    | `VAR CHAR (N) (CHARACTER VARYING (N))` | M байт - кол-во заполненных байт                           | N = 1 : 255                                    |

Многие поля (например BIT) могут быть объявлены как `NULL` или `NOT NULL`. При `NULL` в поле допускается отсутсвие значения, с `NOT NULL` наоборот. `NULL` это не ноль для числового и не пробел для текстового поля.
#### Именование полей

Наименования полей стоит называть одним словом.
**Венгерская нотация** - `имя_тип_размерность`. Так не стоит!
#### DDL (Data Definition Language)

Язык описания структуры таблицы.

**Создание таблицы**:
- `CREATE TABLE <имя_таблицы> (<имя_поля_1> <тип_данных> [NULL|NOT NULL], ..., <имя_поля_n> <тип_данных> [NULL|NOT NULL]);`

**Изменение структуры таблицы**:
- `ALTER TABLE <имя_таблицы> ADD|MODIFY|DROP <имя_поля> [тип_данных] [NULL|NOT NULL], ...;`

**Удаление таблицы**:
- `DROP TABLE <имя_таблицы>`

Аналогично можно создавать и удалять индексные файлы и представления.
#### DML (Data Manipulation Language)

Язык управления записями.

**Вставка записи**:
- `INSERT INTO <имя_таблицы> [(<список_полей>)] VALUES (<список_значений>);`
- `INSERT INTO <имя_таблицы> [(<список_полей>)] SELECT ... ;` - данные для заполнения таблицы предоставляются из оператора выборки `SELECT`.

**Изменение записи**:
- `UPDATE <имя_таблицы>                                                                    SET <имя_поля>=<выражение>                                                        ...                                                                               SET <имя_поля>=<выражение>                                                        [WHERE <условие>];`

**Удаление записи**:
- `DELETE FROM <имя_таблицы> [WHERE <условие>]`;
#### DQL (Data Query Language)

Язык управления запросами.

**Оператор выбора**:
- `SELECT [ALL|DISTINCT|<список_полей>|<выражение>] FROM <список_таблиц>                   [WHERE <условие>]                                                                 [GROUP BY <имя_поля_1>...<имя_поля_n>]                                            [HAVING <условие_поиска>]                                                         [ORDER BY <спецификация>];`
  
  Производит выборку и обработку данных из списка таблиц. Результат выполнения - проекция таблицы, которая может иметь или не иметь повторяющиеся строки. Список после `SELECT` содержит имена полей, участвующих в запросе, а также выражения над столбцами. Если поля из разных таблиц, то указывается имя таблицы: `имя_таблицы.имя_поля`.
