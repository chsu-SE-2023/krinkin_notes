Для построения модели необходимо иметь измерения в ходе эксперимента в виде таблицы:

| Номер эксперимента | $X_1$    | $X_2$    | $X_3$    | ... | $X_k$ | $Y$  |
| ------------------ | -------- | -------- | -------- | --- | ----- | ---- |
| $1$                | $x_{11}$ | $x_{21}$ | $x_{31}$ | ... | $xk1$ | $y1$ |
| $2$                | $x_{12}$ | $x_{22}$ | $x_{32}$ | ... | $xk2$ | $y2$ |
| $3$                | $x_{13}$ | $x_{23}$ | $x_{33}$ | ... | $xk3$ | $y3$ |
| ...                |          |          |          |     |       |      |
| $m$                | $x_{1m}$ | $x_{2m}$ | $x_{3m}$ | ... | $xkm$ | $ym$ |
По этим данным оцениваются коэффициенты регрессии из которых строится запись многофакторной модели.
Коэффициенты определяются с помощью матрицы

$$
X =\begin{pmatrix}
1 & x_{11} & 0 & 0 \\
1 & sy & 0 & 0 \\
1 & 0 & sz & 0 \\
1 & 0 & 0 & 1
\end{pmatrix}
$$
