#### Форматирование

#### Расширения
%%Прохихикано%%
#### var
**var** - переменная с динамической типизацией. 
Лучше описывать переменную с конкретным типом, чем делать каст var в нужный тип.
#### Приведение
Можно перегружать приведение типов.
Приведение может быть явное и неявное
#### Работа с файлами
```
FileStream stream = File.OpenWrite("text.txt");
stream.Write(Encoding.UTF8.GetBytes("Hello, World!"));
stream.Close();
```
Работу с потоковой записью лучш производить через `IDisposable`
