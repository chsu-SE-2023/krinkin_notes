#### Linq

Linq представляет методы для составления запросов похожих на язык SQL. Методы предоставляются System.Linq. Примеры:
``` csharp
List.Where() // Возвращает коллекцию, сформированную по условию
List.Order() // Возвращает коллекцию, упорядоченную по простым типам данных
Array.Sort() // Сортирует исходный массив (быстрее)
List.OrderBy() // Возвращает коллекцию, упорядоченную по условию (медленнее)
List.Contains() // Возвращает содержит ли коллекция элемент
List.Remove() // Удаление элемента
List.RemoveAt() // Удаление элемента по индексу
List.Clear() // Очистка коллекции
List.Except() // Комбинаторика: исключение
List.Intersect() // Комбинаторика: пересечение
List.Distinct() // Комбинаторика: удаление дублирования
List.Union() // Комбинаторика: объединение (уникальное)
List.Concat() // Комбинаторика: объединение (с повторами)
List.Aggregate() // Обрабатывает каждые два элемента коллекции через лямбду
List.Skip() // Пропустить некоторое количество элементов из коллекции
List.Take() // Взять некоторое количество элементов из коллекции
List.GroupBy() // Возвращает словарь групп по условию
```

Для обработки больших объёмов данных лучше использовать отдельные СУБД в угоду производительности. Обработка значимых типов данных работает быстрее, чем ссылочных.

**yield** - машина состояний. Каждый вызов срабатывает каждый следующий yield.

#### Потоки

Класс `Thread`. В конструктор передаётся выполняемый делегат. Для запуска есть метод Start(). Обращение между потоками медленная операция. Все вычисления следует производить внутри потока, а затем уже передавать результат.
#### Процессы

Класс `Process`. У процесса есть стартовая информация `ProcessStartInfo(путь, параметры)`. У процесса есть метод ожидания завершения `WaitForExit()`.
#### Задачи

Механизм быстрого доступа и синхронизации потоков. Класс `Task` - некоторое действие которое выполняется парраллельно мы ожидаем результата и делаем что-то другое.
Задачу можно отложить через `Task.Delay(time);`
Задачи выполняют `async` функции - асинхронные функции разбитые на состояния: до задачи, выполнение задачи, после выполнения задачи. Операция выполнения задачи находится в `await`. Состояние до задачи выполняется, запускается `await` часть и происходит выход из функции и продолжение программы, в то время как асинхронная функция продолжает выполнятся. Для ожидания завершения асинхронной задачи требуется вызов задачи так же обернуть в `await`. Также можно возвращать задачи из функции и результат добавлять в `await`.
Задачи в отличие от потоков могут возвращать данные.
