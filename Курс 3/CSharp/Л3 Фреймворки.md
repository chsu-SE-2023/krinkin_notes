 #### Blazer

Используем "Веб приложение Blazor" для фронтенда
Задача тимлида - развёртывание докера и проекта
- `launchSettings.json` - отладочный файл конфигураций запуска
- `appsettings.json` - файл с конфигурацией готового приложения.
- `appsettings.Development.json` - файл с конфигурацией и паролями. На гите быть не должно!
- Статические глобальные файлы располагаются в `wwwroot`. 

Примерная структура проекта:
- docs/
	- ...
- tests/
	- ...
- src/
	- Frontend/
		- Components/
			- Layout/
				- ...
			- Pages/
				- Page1/
					- Components/
						- ...
					- Index.razor
				- ...
			- Shared/
				- ...
		- Frontend.csproject
	- Backend/
		- ...
- Project.sln

Требуется http клиент для доступа к бекенду

Для бекенда выбираем "Веб-API ASP.NET Core (Майкрософт)"
