#### Свойства

``` 
public class Pen {
	public int Size { get; set; } // Свойство (вместо написания функций геттеров и сеттеров)
	public void Draw(int size = 1) {
		Size -= size;
	}
}
```

Пользовательские свойства
```
public class Pen 
{
	public int Size { get; private set; }
	
	private float _weight { get; set; }
	
	public float Weight
	{
		get
		{
			return _weight; // Можно заменить на лямбду
		}
		set
		{
			_weight = value; // Можно заменить на лямбду. Значение value - задаваемое
		}
	}
}
```

Для быстрого создания свойств можно воспользоваться шаблоном `prop`. 
Для быстрого создания полного (пользовательского свойства) можно воспользоваться средствами VS на созданном свойстве.

В свойствах можно не указывать геттер или сеттер.

Свойства должны называться с большой буквы.

Свойства вызываются и определяются так:
```
Pen p = new();
p.Size = 12; // Сеттер
int s = p.Size; // Геттер
```

#### Конструкторы

Для создания конструктора можно воспользоваться шаблоном `ctor` или средствами VS.
#### Наследование

Абстрактные классы имеют модификатор `abstract`.
Для предотвращения последующего наследования добавляется `sealed`.
`private` поля не будут доступны при наследовании.

Абстрактные функции так же имеют модификатор `abstract`.
Переопределение функции производится модификатором `override`.
Перекрытие функции производится ключевым словом `new`.

Вызвать конструктор базового класса можно вызвать его сигнатурой `base()`:
```
public class Pen2 : Pen {
	public Pen2() : base(100)
	{}
}
```
`base` - ~~указатель~~ ссылка на базовый класс.

В конструктор по умолчанию в качестве параметра можно инициализировать свойство.
`var p1 = new Pen( Size = 100 );`

Для инициализации поля только один раз можно использовать модификатор `readonly` при этом будет создан авто конструктор.

Для того чтобы определить обязательную инициализацию свойства используется ключевое слово `init` вместо `set` (если свойство без сеттера) или ключевое слово `required` (если свойство с сеттером).

Класс лишь хранящий данный - **класс-модель**
Класс лишь обрабатывающий данные - **класс-сервис** (часто он статический). Наследует `IService`.
#### Записи

`public record Pixel(size);` - Создастся конструктор для size.
Данные меняются только при полном или частичном пересоздании.

Множественного наследования в C# не существует. В качестве аналога используется ассоциация.
#### Обобщения

В C# нельзя вызывать функции ~~шаблонов~~ обобщений без указания конкретного типа.

```
public class Sample
{
    public static void Test<T>(T parentOrChild)
    {
	    Console.WriteLine(parentOrChild.DoWorld()); // Ошибка: parentOrChild нет явного указания типа
    }
}
```
Для исправления можно явно преобразовать parentOrChild в базовый тип в иерархии наследования с таким методом. 
Или можно явно указать необходимый интерфейс:
```
public class Sample
{
    public static void Test<T>(T parentOrChild) where T : IParentOrChild
    {
	    Console.WriteLine(parentOrChild.DoWorld());
    }
}
```
Также можно установить ограничение `struct`, `class`(тип) или `new()`(наличие конструктора). Также принимается множество ограничений через запятую.
#### Класс-интерфейс 

Ключевое слово `interface`. Все методы этого класса должны быть реализованы производными классами. 
В C# может быть множественное наследование интерфейсов.
Можно создавать обобщённые интерфейсы.

Функция `nameof()` возвращает наименование типа данных. 
Объект можно проверять на необходимый тип через `is`: `if (something is int) {...}`
