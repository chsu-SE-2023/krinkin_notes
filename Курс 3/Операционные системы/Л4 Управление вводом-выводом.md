#### Системные таблицы
![[Drawing 2026-03-17 16.21.26.excalidraw]]
**Таблица оборудования** содержит Unit Control Block записи о каждом устройстве компьютера: 
- Тип устройства (модель, символическое имя, характеристики устройства)
- Способ подключения устройства (порт, разъём и тд)
- Указатель на драйвер, управляющий устройством
- Информация используется или нет буферизация при работе с устройством
- Установка таймаута и ячейка для значения таймаута
- Состояние устройства

В **таблице логических имён** приведены логические имена, связанные с каждым UCB. Как правило пользователь обращается в УВВ по логическому имени. Как правило существует одна общая таблица логических имён и по одной таблице для каждого пользователя.

**Таблица прерываний** обязана связать каждое прерывание с одним UCB чтобы знать какому драйверу предназначено данное прерывание.
