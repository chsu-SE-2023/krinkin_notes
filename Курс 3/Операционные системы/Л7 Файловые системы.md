**Файл** - поименованная последовательность байт на внешнем носителе. 

**Файловая система** - это набор спецификаций и соответствующее им программное обеспечение, которые отвечают за создание, уничтожение, организацию, чтение, запись, модификацию и перемещение файловой информации, а также за управление доступом к файлам и за управлением ресурсами, которые используются файлами.

Самый первый сектор в HDD - 0-0-1.
#### MBR

Partition Table
Можно адресовать всего 8 ГБ.
#### LBA адресация

1. Сплошная адресация секторов
2. Номер блока (сектора) - 32, 48 бит
3. При размере блока 512 байт возможность адресовать 2ТБ (при 32 бит) или 128Пб (при 48 бит).
#### GPT 

GUID Partition table
При этом в самом начале существует MBR.
#### Файловые системы

##### FAT (File allocation table)

Элемент каталога:
1. Имя файла или каталога - 11 байт
2. Атрибуты файла - 1 байт
3. Резервное поле - 1 байт
4. Время создания - 3 байта
5. Дата создания - 2 байта
6. Дата последнего доступа - 2 байта
7. Резерв - 2 байта
8. Время последней модификации - 2 байта
9. Дата последней модификации - 2 байта
10. Номер начального кластера в FAT - 2 байта
11. Размер байта - 4 байта

FAT32 отличается размером номера начального кластера в FAT.
#### NTFS (New Technology File System)

- Поддержка дисков до 16Эб
- Размер одного файла до 256Тб
- Квоты использования диска
- Шифрованная файловая система EFS
- Поддержка журналирования
- Жёсткие ссылки, разрежённые файлы, точки повторной обработки и т.д.

Все файлы делятся на:
- Small - малые (~2кб) - напрямую хранятся в записи MFT
- Large - большие - в поле DATA хранятся тройки (VCN, LCN, k)
- Huge - очень большие - хранится ссылка на аттрибут DATA в AttributeList
- Extremely Huge - сверхбольшие - создаётся несколько атрибутов DATA, а ссылки на них в AttributeList

Тройка (VCN - Virtual Cluster Name (кластер файла), LCN - Logical Cluster Name (кластер диска), k - штук).

#### ReFS

**Resilient file system (кодовое имя Protogon)** - https://learn.microsoft.com/ru-ru/windows-server/storage/refs/refs-overview

Особенности:
- Целостность данных - контрольные суммы и зеркалирование
- Отказоустойчивость - записывает новые данные в новый блок (copy-on-write), что предотвращает потерю при отключении питания
- Масштабируемость - поддержка томов огромного размера $2^{64}$ байт
- Отсутствие CHKDSK - благодаря B+ деревьям не требуется длительная проверка диска при сбоях

#### EXT

ext (1992) - 2Тб, 255 символов
ext2 (1993) - списки контроля доступа ACL
ext3 (2001) - журналируемость
ext4 (2008) - 64 разрядная, непрерывные области дискового пространства, задержка выделения пространства, онлайн дефрагментация и прочее

**Inode** - индексный дескрипторы - хранит информацию о файлах, такую как принадлежность владельцу, режим доступа, тип файла, в каких блоках находятся данные. Под Inode выделяется примерно 1% объёма ФС.

- Super Block - кол-во блоков данных и inode, количество свободных блоков данных и inode, их размеры, информация об фс
- Group Description Table - где начинается какая группа Inode, начало блоков данных
- Block BitMap - какие блоки использованы, а какие свободны
- Inode BitMap - какие inode использованы, а какие свободны
- Блоки данных - выделенные физические блоки памяти, в которых хранятся данные пользователя
