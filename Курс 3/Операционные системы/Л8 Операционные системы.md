##### Реестр

Первая ступень - 5 ветвей:
- `HKEY_CLASSES_ROOT` - подраздел `HKEY_LOCAL_MACHINE\Software\Classes`. Содержит информацию о зарегистрированных типов файлов
- `HKEY_CURRENT_USER` - настройки текущего пользователя (подветвь `HKEY_USERS`)
- `HKEY_LOCAL_MACHINE` - параметры конфигурации машины
- `HKEY_USERS` - информация о профилях всех пользователей
- `HKEY_CURRENT_CONFIG` - сведения о профиле оборудования при запуске системы
Вторая ступень - разделы, ключи
Третья ступень - подразделы
Четвёртая ступень - параметры
