IP (Internet Protocol) - адрес устройсва в сети

Способы выдачи адреса:
- Статический - администратором
- Динамический - автоматическая выдача временного адреса

Для автоматической выдачи используется DHCP

DHCP - протокол динамической настройки узла. Работают по модели "клиент-сервер". Следит чтобы у каждого устройства был уникальный адрес.
#### Этапы выдачи

- D - Discover - поиск
- O - Offer - предложение
- R - Request - запрос
- A - ... - Подтверждение
##### Этап поиска
Клиент ищет DHCP сервер. Отправляется сообщение DHCP Discover, которое получают все устройства в сети. Ответить на него смогут только DHCP сервера.
##### Этап предложения

DHCP отправляет доступный IP адрес. Может меняться со времененм. Если серверов два, то выбирается любой из них
##### Этап запроса

Клиент получает выделенный IP и отправляет его по сети для подтверждения. Также другие DHCP сервера узнают о занятости адреса.
##### Этап подтверждения

DHCP сервер отправляет информацию об адресе: адрес, срок аренды, и др. Клиент его применяет.
#### Способы раздачи адресов

Фиксированный - выдача происходит по заранее определённой таблице MAC-адресов.
Автоматический - каждому устройству выдаётся адрес в бессрочную аренду.
Динамический - выдаёт любой адрес из диапазона свободных. Эти адреса не закрепляются за устройствами.
#### DNS

Система доменных имён, обеспечивающая работу доменных имён сайтов. Связь осуществляются через IP адреса.
