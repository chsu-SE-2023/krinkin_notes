**Каталог** - информационный ресурс для хранения инфрмации о каким-либо устройстве

**Служба каталогов** - сетевая служба, предоставляющая доступ к каталогу

**Active Directory** - служба каталогов из Mincrosoft Windows начиная с Server 2000

- Упрощённое администрирование
- Масштабируемость
- Поддержка открытых стандартов
- Поддержка стандартных форматов имён

Используется для хранения объектов со своими атрибутами, таких как конфигурация, пользователи и д.р.
#### AD позволяет

- Обеспечивать защиту информации
- Распространять каталог среди пользователей в сети
- Проводить репликацию
- Разделять каталог на несколько частей, обеспечивая возможность хранения большого числа объектов

Функции службы каталогов

#### Проектирование AC

**Область действия группы** - классификация уровней разрешений
**Пространство имён** - ограниченная область, в которой может быть распознано данное имя
**Объект** - не пустой, именованный набор атрибутов, обозначающий нечто конкретное, например пользователь, принтер, приложение
**Контейнер** - аналогичен объекту в том смысле, что также имеет атрибуты и принадлежит пространству имён. Однако в отличие от объекта, контейнер не обозначает ничего конкретного и может содержать группу объектов или контейнеров.
**Домен** - область с различными правами доступа и требованиями безопасности.
Можно организовать **дерево доменов** или **доменный лес**
**Организационные единицы** (подразделения) - разделение домена на зоны административного управления
**Узел** (сайт) - элемент сети, который содержит серверы AC - одна или несколько подсетей TCP/IP

#### Основные компоненты служб

**Системный агент каталогов** - выстраивает иерархию отношений в каталоге. Предоставляет API для доступа к каталогу.

**Уровень БД** - предоставляет уровень абстракции между приложениями и БД.

**Расширяемое ядро хранения** - напрямую взаимодействует с записями в хранилище на основе атрибута относительного составного имени объекта.

**Контроллер домена** - компьютер-сервер, управляющий доменом и хранящий реплику каталога домена.

Функции контроллера домена:
- Хранит полную копию всей информации AD, относящейся к домену
- Автоматически реплицируют все объекты в домене
- Важные обновления реплицируют немедленно
- AD использует репликацию с несколькими хозяевами в котором ни один из контроллеров не является главным. Все контроллеры содержат копию базы каталогов, в которую разрешается вносить изменения.
- Наличие в домене нескольких контроллеров обеспечивает отказоустойчивость
- Управляют взаимодействием пользователей и доменов, например находят объекты AD и распознают попытки входа в сеть.

Роли хозяина репликации:
- Хозяин RID - выделение относительных идентификаторов контроллеров в домене
- Эмулятор основного контроллера - эмуляция Windows Nt 4.0 для других клиентов
- Хозяин инфраструктуры - принимает запросы на изменения и отправяет в другие контроллеры доменов.
#### Концепция сайтов

**Сайт** - группа контроллеров доменов, связанные сетевыми соединениями.

Деление на сайты не зависит от доменной структуры.

Особенности сайтов:
- Оптимизация трафика тиражирования между сайтами по медленным линиям
- Помощь клиентам быстрее обнаруживать ближайшие к ним контроллеры
