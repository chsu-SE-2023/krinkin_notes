**Каталог** - информационный ресурс для хранения инфрмации о каким-либо устройстве

**Служба каталогов** - сетевая служба, предоставляющая доступ к каталогу

**Active Directory** - служба каталогов из Mincrosoft Windows начиная с Server 2000

- Упрощённое администрирование
- Масштабируемость
- Поддержка открытых стандартов
- Поддержка стандартных форматов имён
