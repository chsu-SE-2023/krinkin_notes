#### IP-адрес

##### IPv4
32-битное бинарное число (длина 4 байта)
Записывается в виде 4-х десятичных чисел от 0 до 255
Состоит из 4-х октетов ($256=2^8$)

128.10.2.30 - десятичная форма представления
10000000 00001010 00000010 00011110 - двоичная форма представления

Логически состоит из двух частей:
- адрес сети (Network) - номер сети показывает к какой сети принадлежит адресат
- адрес машины (Host) - идентифицирует адресата в сети
###### Классы IPv4-адресов

Примерное разбиение адресов в зависимоти от класса сети на сетвую (N) и машинную (H) части

|     | 1 октет |
| --- | ------- |
|     |         |

...


- Если весь IP-адрес состоит из нулей, то он обозначает адрес того узла, который сгенерировал этот пакет.
- ...
##### Порядок распределения адресов 

Адреса назначаются либо организовано:
- либо централизовано, если являются частью Internet
- либо произвольно, если сеть работает автономно

Номера узлов администратор назначает по своему усмотрению, не выходя из разрешённого для этого класса сети диапазона.
##### Маска

Чтобы гибко устанавливать границу между номером сети и номером узла используется маска - число, которое используется в паре с IP-адресом.

Двоичная запись маски содержит единицы в тех разрядах, которые должны в IP-адресе интерпретировать как номер сети. Поскольку номер сети является цельной частью адреса, единицы в маске также должны представлять непрерывную последовательность.

Маска подсети для целой сети:
- класс А - 255.0.0.0
- класс B - 255.255.0.0
- класс С - 255.255.255.0
##### Дефицит IP-адресов

Очень трудно получить адрес класса B и невозможно стать обладателем класса A.
Дефицит обусловлен:
- ростом сетей
- имеющееся множество IP-адресов использующихся нерационально (используются не все 254 адреса)

Решение проблемы:
- технологии направленные на более экономное расходование адресов:
	- Технология масок и её развитие - технология безклассовой междоменной маршрутизации (**CIDR**).
	- Технология трансляции адресов (Network Address Translator, **NAT**) - внутренняя компьютерная сеть работает автономно и подключена к маршрутизатору, который уже имеет адрес во внешней компьютерной сети 
- переход на новую версию адресации **IPv6** - резкое расширение адресного пространства за счёт использования 16-ти байтного адреса (128 бит). 340 ундецилионов адресов ($340$ $282$ $366$ $920$ $938$ $463$ $374$ $607$ $431$ $768$ $211$ $456$).
  Пример: `2001:0db8:0000:0000:0000:0000:0010:ad12`
#### MAC-адрес

MAC-адрес - уникальная комбинация цифр и букв длиной 48 символов. Аппаратный номер оборудования (компьютера, сервера, роутеров, порта коммутатора), присваивается сетевой карте устройства ещё на фабрике, то есть в момент производства вшит аппаратно.

MAC - уникальный физический адрес устройства, помогающим идентифицировать устройство среди миллионов других.
В стандарте IEEE 802, канальный (второй) уровень модели OSI разделён на два подуровня:
- Logical Link Control (LLC)
- Media Access Control (MAC)

Состоит из 6-ти октетов. Первые 6 чисел означают производителя (OUI). Следующие 6 чисел идентифицируют сетевой адаптер.

Формат: `XX:XX:XX:XX:XX:XX`
