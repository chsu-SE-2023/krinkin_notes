**Декомпозиция** - разбиение одной задачи на несколько задач-модулей

**Иерархическая декомпозиция** - чёткое определения каждого уровня и интерфейсов между уровнями (функции предоставляемые нижними уровнями), а также относительная независимость уровней.

#### Модель взаимодействия двух узлов компьютерной сети

![[Drawing 2026-10-08 15.39.51.excalidraw]]

**Протокол** - формализованные правила, описывающие взаимодействие с узлами на одном уровне
**Интерфейс** - формализованные правила, описывающие взаимодействие между уровнями
**Стек простоколов** - иерархически организованный набор протоколов, достаточный для реализации взаимодействия улов в сети

Нижние уровни реализуются комбинацией железных и программных средств, а более высокие - программно.

Протоколом можно называть программный модуль, реализующий этот протокол.

**OSI (open system interconnection)** - определяет различные уровни взаимодействия систем в сетях с коммутацией пакетов, даёт им стандартные имена и указывает какие функции должен выполнять каждый уровень. Сумиуровневая модель протоколов передачи данных, для сопряжения различных видов коммуникационного оборудования различных производителей.

**Уровни ISO/OSI** - группы протоколов передачи данных, связанные между собой иерархическими отношениями. Каждый уровень обслуживает вышестоящий уровень и, в свою очередь, пользуется услугами нижестоящего:

| **Тип данных** | **Уровень**          | **Функции**                                                         |
| -------------- | -------------------- | ------------------------------------------------------------------- |
| Данные         | 7. Прикладной        | Доступ к сетевым службам                                            |
|                | 6.  Представительный | Представление и кодирование данных                                  |
|                | 5. Сеансовый         | Управление сеансом сети                                             |
| Сегменты       | 4. Транспортный      | Прямая связь между конечными маршрутами и надёжность                |
| Пакеты         | 3. Сетевой           | Определение маршрута и логическая адресация                         |
| Кадры          | 2. Канальный         | Физическая адресация                                                |
| Биты           | 1. Физический        | Работа со средой доставки, передачей сигнала, доставленными данными |

**Протокольный блок данных** - единица данных, с которой имеют дело протоколы разных уровней
**Пакет** (packet), **кадр** (frame), **дейтаграмма** (datagram), **сегмент** (segment) - блок данных определённых уровней 

Каждый пакет содержит полезную информацию и заголовки для каждого из уровней: на 7 уровне - один заголовок, на первом - семь.
