- Одновременное выполнение нескольких действий
- Ускорение вычислений (при наличии нескольких высокопроизводительных ядер)
#### Закон Амдала
 
 $S(N) = 1/((1 - P) + P/N)$
 $S$ - ускорение (speedup)
 $P$ - доля вычислений, которые возможно параллелить
 $N$ - количество вычислительных ядер

public class Account {

	private static class MyThread2 extends Thread {

##### Ключевое слово synchronized

- Синхронный метод - `public synchronized void doSomething() {...}`
- Синхронизированный блок внутри метода
``` java
public void doSomething() {
	synchronized(obj) {...}
}
```

Получится:
``` java
package mypack;

public class Account {
	int balance;
	public Account(int balance) {
		this.balance = balance;
	}
	public synchronized void put(int sum) { balance += sum; }
	public synchronized void get(int sum) { balance -= sum; }
	public int show() { return balance; }
}
```

Реализовано это при помощи мониторов объектов. Когда поток начинает работать с счётом аккаунт, то он захватывает монитор. Пока монитор захвачен - доступа к захваченной переменной нет.

Преимущество: просто
Недостаток: серьёзное замедление
##### Ожидание и уведомления

Допустимо только в блоке synchronized
- `void wait()` - ожидание разбокировки
- `void wait(long millis)` - ожидание с таймаутом
- `void wait(long millis, int nanos)` - ожидание с таймаутом
- `void notify()` - отпускает монитор
- `void notifyAll()` - отпускает все захваченные монитор
##### Ключевое слово volatile

При работе потоков при описании каких-то переменных можно их описывать с модификатором volatile. Таким образом процессор не будет вносить переменную в кэш-память. Таким образом не возникнет неожиданных ситуаций когда значение в кеше не успело перенестись в ОЗУ.

``` java
public class SharedObject {
	public volatile int counter = 0;
}

public class MyClass {
	private int years;
	private int months;
	private volatile int days;
	public void update(int years, int months, int days) {
		this.years = years;
		this.months = months;
		this.days = days;
	}
}
```

#### Семафоры (класс `java.util.concurrent.Semaphore`)
- В отличие от synchronized-блока, одновременно могут работать несколько потоков (но не более N)
- Операции:
	- void acquire()
	- void release()

```
Semaphore semaphore = new Semaphore(10);
semaphore.acquire()
try {
	...
} finally {
	semaphore.release();
}
```

``` java
public class Main {

	private static class MyThread1 extends Thread {
		private final Semaphore sem;
		MyThread1(Semaphore sem) { this.sem = sem; } 
	
		@Override
		public void run() {
			try {
				foo();
			}
			catch (InterruptedExecution e) {
				System.out.println(getName()+" interrupted");
			}
		}
		
		public void foo() throws InterruptException {
			while (true) {
				sem.acquire();
				try {
					System.out.println(getName()+" acquired sem");
					Thread.sleep(2000);
				} finally () {
					System.out.println(getName()+" released sem");
					sem.release();
				}
			}
		}
	}

	public static void main() {
		Semaphore sem = new Semaphore(2, true);
		List<Thread> lth = new ArrayList<>();
		for (int i = 0; i < 10; i++) {
			MyThread1 th = new MyThread1(sem);
			lth.add(th);
			th.start();
		}
		Thread.sleep(20000);
		for (Thread th : lth)
			th.interrupt();
		System.out.println("Main thread");
	}
}
```

#### Класс java.util.concurrent.CountDownLatch

- Обеспечение точки синхронизации между n потоками (несколько потоков могут дожидаться друг друга и потом стартовать одновременно)
- Операции:
	- `void countDown()`
	- `void await()`

`CountDownLatch latch = new CountDownLatch(10);`

``` java
public class Main {

	private static class MyThread1 extends Thread {
		CountDownLatch latch;
		MyThread1(CountDownLatch latch) { 
			this.latch = latch; 
			new Thread(this).start();
		} 
	
		@Override
		public void run() {
			for (int i = 0; i < 5; i++) {
				System.out.println(getName()+" "+i);
				latch.countDown();
				Thread.sleep(1000);
			}
		}
	}

	public static void main() {
		CountDownLatch cdl = new CountDownLatch(10);
		System.out.println("Beginning thread");
		new MyThread1(cdl);
		new MyThread1(cdl);
		try {
			cdl.await();
		} catch (InterruptException ex) {
			System.out.println(ex);
		}
		System.out.println("Main thread");
	}
}
```
