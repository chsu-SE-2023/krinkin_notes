### Физическая и логическая адресация адресного пространства

Для адресации операндов в физическом адресном пространстве программы используют логическую адресацию. Процессор автоматически транслирует логические адреса в физические, выдавая их затем на системную шину. Архитектура компьютера различает физическое адресное пространство и логическое адресное пространство. Физическое адресное пространство представляет собой простой одномерный массив байтов, доступ к которому реализуется апаратурой памяти по адресу, присутствующему на шине адреса микропроцессорной системы. Логическое адресное пространство организуется программистом исходя из потребностей. Трансляцию логических адресов в физические осуществляет блок умравления памятью MMU. ЛАП представляется в виде набора элементарных структур: байтов, сегментов и страниц. В микропроцессоре используются следующие варианты организации ЛАП:
- Плоская или линейная ЛАП - состоит из массива байтов, не имеющего определённой структуры. Логический адрес совпадает с физическим.
- Сегментированная ЛАП - состоит из сегментов, логический адрес делится на две части: идентификатор сегмента, смещение внутри сегмента. Трансляцию адреса проводит блок сегментации MMU.
- Страничная ЛАП - состоит из страниц - непрерывных областей памяти, каждая из которых содержит фиксированное число байтов. Логический адрес состоит из номера страницы и смещения внутри страницы. Трансляцию логического адреса в физический осуществляет блок страничного преобразования MMU.
- Сегментно-страничная ЛАП - состоит из сегментов, которые состоят из страниц. Логический адрес состоит из идентификатора сегмента и смещения внутри сегмента. Блок сегментного преобразования MMU проводит трансляцию логического адреса в номер старницы и смещения в ней, которые затем транслируются в физический адрес блоком страничного преобразования MMU.

Сегментные регистры содержат старшие 16 бит базового адреса сегмента. Сдвинутый на 4 разряда влево селектор даёт 20-ти разрядный базовый адрес. Смещение в сегменте формируется либо по заданному режиму адресации операнда, либо извлекается из регистра EIP для команды. Физический адрес получается путём сложения базового адреса и смещения.

#### Схема получения физического адреса в защищённом режиме

В защищённом режиме объём памяти увеличивается до 4ГБ, появляется возможность страничного режима адресации, сегменты имеют переменную длину. Логический адрес состоит из двух частей: селектор и смещение внутри сегмента. Селектор содержится в сегментно регистре и позволяет найти описание сегмента в специальной таблице дескрипторов. 32-х разрядное поле определяет начало сегмента в любой точке адресного пространства. Поле предела указывает длину сегмента -1 в адресуемых единицах. Величина адресуемой единицы определяется битом G. G=0 - длина в байтах, G=1 - длина в страницах. Бит размерности D определяет длину адресов и операндов используемых в командах по умолчанию. D=0 - длина в байтах, D=1 - длина в страницах. Бит пользователя U может использоваться системным программистом по усмотрению. Процессор в своей работе его не использует и не меняет. 
Байт доступа определяет основные правила обращения с сегментом. Бит присутствия P показывает возможность доступа к сегменту. P=1 - сегмент находится в физической памяти, P=0 - сегмент находится в виртуальной памяти. Двухразрядное поле DPL указывает один из 4-х возможных (0-3) уровней привилегий дескриптора, определяющие возможность доступа к сегменту со стороны программ (нулевой - самый высокий). Вид обращения A - при любом обращении к сегменту устанавливается в единицу. Используется ОС чтобы отслеживать сегменты к которым давно не было обращений. Вид S=1 - дескриптор описывает реальный сегмент памяти. S=0 - дескриптор описывает специальный системный объект. Поле типа определяет назначение и особенности использвания сегмента.

В сегменте кода бит подчинения C определяет правила обращения с защитой сегмента. C=1 - данный сегмент является подчинённым и лишается защиты по привилегиям. C=0 - обычный сегмент кода. Бит считывания R устанавливает правила обращения к сегменту. R=0 - допускается только выборка команд для выполнения. R=1 - допускается выполнение и чтение данных из сегмента, запись в сегмент кода запрещена (возникает программное прерывание). В сегменте данных ED - бит направления расширения. ED=1 - сегмент является сегментом стека и смещение в сегменте должно быть больше размера сегмента. ED=0 - обычный сегмент данных, смещение меньше или равно размеру сегмента. W - бит разрешения записи. W=1 - запись разрешена. W=0 - запись запрещена, возникает программное прерывание.
